# LT-1

## Description

This program calculates the number of boxes that are full with notebooks, and the number of notebooks left behind in a loose pack using the total number of notebooks and how much notebooks can fit in a box, using input values, and // and %


## How to Run

1. Open the program file in Python or VS Code.

3. Run the program.

4. Enter the values for total_notebooks and fit_in_box.

5. Check the number of full boxes and the number of loose notebooks left over displayed on the screen.

6. Also check if the order fills a box or not.


## Input Needed

- total_notebooks
- fit_in_box

## Sample Output
What is the total number of notebooks? 17.9

How many notebooks fit in one box? 2.6

The total number of notebooks is 18 , and you can fit 3 in one box.

The number of full boxes is 6

The number of loose notebooks is 0
